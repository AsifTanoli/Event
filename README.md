# Event

This repo contains a small React + TypeScript demo showcasing a reusable `DynamicForm` component with built-in validation (email/name/Emirates ID/DOB/phone), and support for both controlled and uncontrolled usage.

## Development

```bash
npm install
npm run dev
```

## Key files

- `src/components/DynamicForm.tsx`: the reusable dynamic form component
- `src/App.tsx`: demo page exercising validation rules
